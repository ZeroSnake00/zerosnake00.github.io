About / Manifesto

Player first.
Then everything else.

I'm a multimedia undergraduate at NSBM, but I learned most of what I know about games by playing them — obsessively, critically, and with a notepad open. The Division 2. Cyberpunk 2077. Honkai: Star Rail. Hours sunk into systems, level flow, encounter design, UI craft.

On the build side I work across the full pipeline: level design for a team game project, 3D character modelling in VRoid Studio, full web platforms in HTML / CSS / JavaScript, and UI / visual design in Photoshop and Illustrator. The thread tying it all together is the same question — what makes this feel good to play?

The long arc: ship games people love, then build the studio that makes more of them. The short arc: keep learning, keep shipping, keep getting better.

Original character

3D Artist VRoid Studio Multimedia coursework 2024

Designed and modelled an original 3D character in VRoid Studio — silhouette, proportions, facial parameters, outfit composition, and texturing. End-to-end character pipeline thinking, built with the long-term ambition of slotting models like this straight into a game engine.

P/04

Fantasy scene
— photo composite.

Digital Artist Adobe Photoshop Concept / Environment 2024

A composited fantasy environment built in Photoshop — dragon, glowing enchanted blades, blood moon, lava river, and a cliff with figures for scale. The work is in the integration: matching light direction, colour grading every element to one palette, and layering atmospheric haze so separate stock pieces read as a single believable world. Exactly the mood-and-scene thinking that feeds game environment art.
